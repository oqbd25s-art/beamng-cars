# BeamNG Cars

مجموعة سيارات BeamNG.drive، معدّلة وجاهزة للتركيب.

## التحميل
كل السيارات موجودة في **[Releases](../../releases/latest)**. كل ملف zip سيارة كاملة.

## التركيب
- **يدوي:** حط ملف الـ zip مثل ما هو في مجلد المودات:
  `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods`
- **من iQorZ1:** صفحة السيارات ← «اربط من GitHub» ← الصق رابط الـ Release.

## الصور
صور السيارات في مجلد [`pictures`](pictures).
